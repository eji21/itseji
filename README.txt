HOW TO ADD YOUR PROJECT PHOTOS
================================
1. Copy your photo/screenshot files into this  images/  folder.
2. Open index.html in a text editor.
3. Find the four <img> tags inside the Projects section.
4. Replace the src attribute with your actual filename, for example:
     src="images/capstone-screenshot.jpg"
5. Save index.html and you're done!

Recommended image size: 800 x 450 px (landscape, 16:9 works best).
